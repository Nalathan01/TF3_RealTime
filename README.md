# Real Time

In Transport Fever 3 the vehicles move at a normal pace, but the calendar races ahead: a short train ride eats up months, even on the slowest calendar speed. Real Time lets you set a date and a time of day, then calendar and day/night cycle run in real time. One minute in game is one real minute.

## Features

- Set date and time of day in a small window, or take the time from your PC clock
- Calendar and lighting run together in real time, the date changes at midnight
- Time lapse from 10x up to 3600x (one hour per second), only the clock speeds up, vehicles keep their normal speed
- Normal game speeds (pause, 2x, 4x) still work on top
- Clock shown in the game bar, one click opens the settings
- German, English and French

## Installation

Copy the folder `nalathan_echtzeit` into your Transport Fever 3 local mods folder and activate "Real Time" when loading a savegame.
